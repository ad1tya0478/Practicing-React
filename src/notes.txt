React is a Javascript library, used for rendering User Interfaces(UI). UI is built from small units like buttons, text, Images ETC. 
React lets you combine them into components that are reusable, nestable. 
we can declare many components in one file, but large files are hard to navigate. JSX Lets you write HTML-like markup inside a JS file, keeping rendering logic and content in the same place.
we can use Filter() and map() methods of JS to display multiple components from a collection of data to transform your array into an array of components.

3 Different Ways to Style React components:-

i. External - Which is Great for global styles, and small Projects.
ii. Modules - Preferred For individual components that have their own unique styles.
iii. Inline - This tends to be good with any small components with minimal styling.
